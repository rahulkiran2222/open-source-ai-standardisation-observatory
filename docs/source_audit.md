## Candidate relationship audit template

- Relationship ID
- Project / organisation

- Exact supporting passage
- Access date (`YYYY-MM-DD`)
- Coder decision (`verified` / `needs_review` / `rejected`)

Do not fill missing fields from inference. If a source does not support a direct relationship, record that decision and do not create a verified edge.
